Print RC uses one source tree with English and Brazilian Portuguese. The GNU X11 candidate replaces full-static glibc packaging, verifies rendered-overlay readiness and preserves single-folder installation, screenshots, annotations and reversible shortcuts. Read CHANGELOG.md and the exact build manifest.

A release is publishable only after the archive's ABI/core tests and actual Zorin 17.3/XFCE and Q4OS/Trinity acceptance evidence pass. An unreleased development candidate is not a compatibility claim. Wayland, ARM64 and musl remain unsupported.
